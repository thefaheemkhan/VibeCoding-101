# Roadmap

This roadmap serves two purposes: it is both a **learning curriculum**
(the order we recommend reading in) and a **project status tracker**
(what's written vs. planned).

## How to read the status column

- ✅ Published — complete, reviewed, ready to use
- 🚧 In progress — scaffolded, being written
- 📋 Planned — not started yet, tracked as a GitHub Issue
