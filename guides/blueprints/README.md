## How to Use a Blueprint

1. Read the whole blueprint before prompting — it's designed to be a
   planning reference per [Planning](../../docs/08-planning/README.md).
2. Adapt scope to your actual v1 — blueprints show a complete picture,
   not all of which you need on day one.
3. Feed relevant sections into your AI tool as grounding context per
   task, rather than pasting the whole blueprint into every prompt.
